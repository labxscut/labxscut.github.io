Command-line interface

The installed package also provides the sigma command. Save the following configuration as config.json, adjusting the paths to your input data and a new output directory:

{
  "preset": "lymph",
  "data_root": "data/Lymph-S1-S2-S3",
  "output": "results/lymph",
  "device": "cpu"
}

Check the installation, inspect the resolved command, and run preprocessing and training:

sigma doctor
sigma run --config config.json --dry-run
sigma run --config config.json --prepare-only
sigma run --config config.json --resume

Paths in a JSON configuration are relative to that file. --dry-run validates the configuration without executing the pipeline. --resume requires the same resolved configuration as the saved run. Change the output directory when changing experiment settings.

sigma doctor reports Python/model import checks and the availability of R/mclust. Every reported entry should have "ok": true before running a workflow. Use sigma --version to display the installed package version.
