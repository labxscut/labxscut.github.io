sigma.run

sigma.run(config, *, prepare_only=False, dry_run=False, resume=False, log_file=None)

Execute a SIGMA preset through isolated Python worker processes.

Parameters:

  • config (dict, str, or pathlib.Path) – Configuration dictionary or path to a JSON configuration file. See sigma.validate_config() for supported fields and path resolution.

  • prepare_only (bool) – Run preprocessing without training. Default: False.

  • dry_run (bool) – Return the resolved configuration and worker command without executing the workflow. Default: False.

  • resume (bool) – Allow reuse of a nonempty output directory when its saved configuration matches exactly. Default: False.

  • log_file (str, pathlib.Path, or None) – Optional path for worker stdout and stderr. Its parent directory is created if needed. When omitted, output is displayed in the current terminal or notebook. Relative log paths are relative to the current working directory.

Returns:

With dry_run=True, a dictionary containing config (the resolved configuration) and command (a list of command arguments). Otherwise, a subprocess.CompletedProcess for the completed worker.

Return type:

dict or subprocess.CompletedProcess

Raises:

  • FileNotFoundError – The input directory does not exist when executing the workflow.

  • FileExistsError – The output directory is nonempty and resume is False.

  • ValueError – Configuration validation fails, or resumption cannot match the saved configuration.

  • subprocess.CalledProcessError – The worker exits unsuccessfully.

  • RuntimeError – A training run does not produce successful trial reports.

Examples

from sigma import run

config = {
    "preset": "lymph",
    "data_root": "data/Lymph-S1-S2-S3",
    "output": "results/lymph",
    "device": "cpu",
}

planned = run(config, dry_run=True)
print(planned["command"])

run(config, prepare_only=True, log_file="results/lymph/preprocessing.log")
result = run(config, resume=True, log_file="results/lymph/training.log")

Outputs and resumption

The function writes sigma_run_config.json under the output directory and passes the same resolved settings to the workers. Preprocessed data are stored under assets/; training results are stored under runs/. The integration notebooks demonstrate loading the saved representations and clustering results.

The return value is a process result; embeddings and AnnData objects are read from the saved files. For training runs, run checks that trial reports exist and that their statuses are "ok". The preprocessing-only path does not perform this training-report check.

dry_run=True does not check that the input directory or individual input files exist. It resolves and validates settings without creating the output directory or starting a worker.

When resuming a nonempty output directory, its saved sigma_run_config.json must match the current resolved configuration exactly. Use a new output directory for another parameter combination.
