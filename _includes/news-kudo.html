{%- comment -%} Kudo line for a paper announcement: credits the (co-)first and (co-)corresponding authors as @-mentions that link to their /team/ pages. Usage: {% include news-kudo.html paper=paper %} Roles are read from the publication record's own `authors[].role`, never from the broadcast prose in labxManage `message.pa.md`. That distinction is load-bearing: the PA text is written before the version of record and goes stale. Duan2025sxSNF's PA credits Chen/Wang as co-first authors, while the registry — corrected from the published VoR and Crossref — records them as co-authors, with Liu + Xia as co-corresponding. Deriving from the record means the public site can never contradict /publications/. Role vocabulary (registry): first_author, co_first_author, corresponding_author, sole_author, co_author. Only the credited roles are named here; co-authors are already listed on the card's author chips, so repeating them would bury the credit this line exists to give. A paper whose record carries no credited role gets no kudo line: claiming a first author the registry does not assert would be fabrication. {%- endcomment -%} {%- assign kudo_paper = include.paper -%} {%- assign kudo_first = kudo_paper.authors | where: "role", "first_author" -%} {%- assign kudo_cofirst = kudo_paper.authors | where: "role", "co_first_author" -%} {%- assign kudo_corres = kudo_paper.authors | where: "role", "corresponding_author" -%} {%- assign kudo_sole = kudo_paper.authors | where: "role", "sole_author" -%} {%- assign kudo_groups = 0 -%} {%- if kudo_first.size > 0 -%}{%- assign kudo_groups = kudo_groups | plus: 1 -%}{%- endif -%} {%- if kudo_cofirst.size > 0 -%}{%- assign kudo_groups = kudo_groups | plus: 1 -%}{%- endif -%} {%- if kudo_corres.size > 0 -%}{%- assign kudo_groups = kudo_groups | plus: 1 -%}{%- endif -%} {%- if kudo_sole.size > 0 -%}{%- assign kudo_groups = kudo_groups | plus: 1 -%}{%- endif -%} {%- if kudo_groups > 0 -%} {%- assign kudo_line = "" -%} {%- assign kudo_done = 0 -%} {%- comment -%} Precomputed rather than written as `kudo_done == kudo_groups | minus: 1`: a filter inside a comparison relies on Liquid's precedence rules, and getting it wrong silently drops the serial comma before the last group. {%- endcomment -%} {%- assign kudo_last = kudo_groups | minus: 1 -%} {%- comment -%} Each group renders as "
